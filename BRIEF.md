# PROMPT — Landing corporativo para grupo empresarial en México

Actúa como un **Senior Full Stack Developer + Senior UI/UX Designer + Art Director especializado en sitios corporativos B2B de alto nivel**.

Quiero desarrollar un **landing page corporativo, moderno, profesional, visualmente impactante y orientado a conversión**, que funcione como la página principal de un grupo empresarial con tres divisiones:

1. **Industria**
2. **Logística**
3. **Inmobiliaria**

El objetivo principal del sitio es **generar nuevos clientes y transmitir confianza, capacidad operativa, infraestructura, innovación y solidez empresarial**.

No quiero un sitio que parezca una plantilla genérica. Debe sentirse como una empresa mexicana consolidada, moderna y capaz de atender proyectos importantes.

---

# 1. Concepto general

El sitio debe presentar las tres divisiones como parte de un **mismo grupo empresarial**, compartiendo:

* estructura visual
* tipografía
* sistema de botones
* navegación
* espaciados
* componentes
* animaciones
* estilo fotográfico
* lenguaje corporativo

Pero cada división debe tener una **personalidad visual ligeramente diferente**, de acuerdo con su industria.

La idea visual debe comunicar:

> **Un grupo empresarial que conecta industria, logística e infraestructura para crear soluciones integrales para otras empresas.**

El diseño debe ser:

* Premium
* Corporativo
* Moderno
* Tecnológico
* Sobrio
* Elegante
* Dinámico
* B2B
* Orientado a conversión

Evitar completamente:

* diseños genéricos de SaaS
* exceso de gradientes
* exceso de tarjetas
* colores demasiado infantiles
* animaciones innecesarias
* aspecto de startup pequeña
* interfaces saturadas
* fotografías de stock demasiado evidentes
